# Ala-Too Fire Calendar

**Открыть приложение: [nasa.vakuum.cc](https://nasa.vakuum.cc).**

Календарь спутниковой пожарной активности Кыргызстана и соседнего пояса. Нарисуйте область на карте, выберите период, сравните месяцы с историей и экспортируйте исходные детекции или месячный ряд.

**Единица анализа:** сумма уникальных ячеек 0.01° с детекцией по дням (`hotspot_days_1km`). Это приближённая пространственная шкала, не число пожаров и не выгоревшая площадь. Данные MODIS и VIIRS SNPP приводятся к шкале MODIS робастной регрессией на перекрытии; 2024–2025 исключены из обучения. Результаты нельзя заранее обещать равными заданному коэффициенту.

Текущий проверенный снимок: **01.11.2000–14.11.2026**, **292 620** исходных детекций.

| Проверка | До калибровки | После | Эталон |
|---|---:|---:|---:|
| Скачок 2012 года к 2009–2011 | 2.78 | 0.78 | 0.58 — сам MODIS |
| Отношение VIIRS/MODIS, hold-out 2024–2025 | 3.63 | 1.02 | 1.00 |
| Отношение VIIRS/MODIS, проспективно 2026 | 4.61 | 1.25 | 1.00 |
| WAPE месячной суммы региона, 2024–2025 | — | 23.1% | — |

MODIS продолжал наблюдения в 2012 году, поэтому калиброванный скачок сравнивается с тем, что увидел MODIS, а не с единицей. Ошибка растёт с уменьшением области: для отдельной ячейки 0.25° WAPE около 91%. Это исследовательское демо, точность для оперативных решений не подтверждена. Подробности и методика — в `docs/method.md`.

## Рабочие сценарии

- Сохранить до 12 областей с месяцем, периодом и палитрой в текущем браузере.
- Передать ссылку на выбранный анализ или импортировать/экспортировать WGS84 GeoJSON.
- Сравнить сезонный профиль выбранного года с медианой и межквартильным диапазоном истории.
- Скачать автономный HTML-отчёт с геометрией, исходными показателями, покрытием и методикой; открыть его для печати в PDF.

## Запуск

Python 3.12+, Node.js 24+. Команды из корня репозитория:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements-dev.txt -r pipeline/requirements.txt
PYTHONPATH=pipeline python -m firebros.build --download archive
uvicorn app.main:app --app-dir backend --port 8000
```

Архив NASA скачивается без ключа для пяти стран, покрывающих регион. Загрузка возобновляемая: ранее проверенные файлы используются повторно. Годовые архивы покрывают завершённые опубликованные годы. Текущий год требует Area API с `FIRMS_MAP_KEY` или локальной выгрузки с метаданными покрытия. Для полного обновления загрузите окружение (`set -a; source .env; set +a`) и выполните `PYTHONPATH=pipeline python -m firebros.build --download all`. Ключ передавайте через окружение, не через аргументы командной строки и не в репозиторий.

```bash
cd frontend
npm ci
npm run dev
```

Откройте `http://localhost:5173`. По умолчанию интерфейс обращается к API. Пока реальных Parquet нет, API явно возвращает `source: mock`. Для отдельного просмотра фикстур задайте `VITE_USE_MOCK=true`. Для производственного запуска `FIREBROS_REQUIRE_DATA=true` запрещает незаметную подмену отсутствующих данных фикстурами.

```bash
pytest

ruff check .
ruff format --check .
cd frontend
npm run format:check

```

Тесты проверяют контракт JSON, геометрию AOI, согласованность CSV, реальные Parquet-чтения, точное окно аномалии, разделение обучения и hold-out, воспроизводимость pipeline и отказ при некорректных данных.

## Контейнер

Сначала соберите данные. Затем `docker compose up --build` запускает API и собранный фронтенд на `http://localhost:8000`: непривилегированный процесс, файловая система только для чтения, read-only том данных, ограничение памяти. Приложение само выставляет CSP без `unsafe-eval`, запрет встраивания во фреймы и остальные заголовки безопасности; DuckDB читает только каталог снимка и не может писать файлы или ставить расширения. Хэшированные ассеты кэшируются на год, HTML ревалидируется, ответы API не кэшируются. Для публичного хостинга нужен TLS reverse proxy. Не пересобирайте активный том данных: собирайте отдельный каталог и переключайте снимок с перезапуском сервиса.

## Устройство

```text
NASA FIRMS CSV → ingest → 0.01° cell-days → 0.25° месяцы
                                             ↓
                       калибровка 2°/сезон + hold-out
                                             ↓
                  Parquet + manifest + отчёт валидации
                                             ↓
                   FastAPI → React / Leaflet / Plotly
```

`days_observed` означает дни, покрытые выгрузкой, а не гарантированно безоблачные пролёты. Пропуски отличаются от наблюдаемого нуля. Неполные месяцы сравниваются с накопительными историческими окнами; при отсутствии точного окна API отказывает, а не интерполирует полные месяцы.

Числа для выступления берутся только из `data/processed/harmonization_report.json`. Наличие Parquet означает формат хранилища; качество модели определяется отдельной валидацией. Временной скачок 2012 года содержит также реальную межгодовую изменчивость, поэтому отдельно рассчитывается отношение сенсоров за одни и те же месяцы.

NASA FIRMS — MODIS/VIIRS active fire data. [Источник и описание продуктов](https://firms.modaps.eosdis.nasa.gov/). NASA не подтверждает и не сертифицирует это приложение.
